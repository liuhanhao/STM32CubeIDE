## 芯片信息

### 主控芯片

- **型号**: STC89C52RC
- **封装**: DIP-40 / PDIP-40
- **Flash**: 8KB
- **RAM**: 512 Bytes
- **I/O端口**: 32个（P0、P1、P2、P3）
- **定时器**: 3个（Timer0、Timer1、Timer2）
- **串口**: 1个全双工UART
- **中断源**: 6个
- **工作电压**: 5V

> **版本说明（原理图标注）**:
> - **90C版本**: 无EA、PSEN引脚，有 P4.4 / P4.5 / P4.6 口
> - **HD版本**: 有EA、PSEN引脚，无 P4.4 / P4.5 / P4.6 口

## 电源系统

### 供电方式

#### USB Type-C 供电（USBC1）

- **接口型号**: TYPE-C-3.1 母头，16P
- **电压**: VBUS → 5V
- **引脚定义**:

| 引脚编号 | 信号名 | 说明 |
|---------|--------|------|
| A4, A9  | VBUS   | 5V电源输入 |
| A1, A12 | GND    | 地线（A侧） |
| B1, B12 | GND    | 地线（B侧） |
| A5, B5  | CC1    | 配置通道1 |
| A6, B6  | CC2    | 配置通道2（原理图为CC2/SBU1/SBU2/DN1/DP1/DN2/DP2等多组差分对） |
| A7, B7  | DM     | USB D-（差分负） |
| A8, B8  | DP     | USB D+（差分正） |

#### 保险丝保护

- **型号**: SMD1812P110TF/33（或 SMBJ5.0A-E3/52）
- **功能**: 自恢复保险丝，限流保护USB供电线路

#### 整流/稳压

- **DR1**: SS-12F23（肖特基二极管），防反接保护
- **S1**: SS-12F23（拨动开关）控制供电通断
- **输出**: 5V 稳定直流供开发板使用

#### 去耦电容

| 元件 | 容量 | 位置说明 |
|------|------|---------|
| C1   | 104 (100nF) | VCC 电源去耦 |
| C3   | 104 (100nF) | KEY1 旁路电容 |
| C6   | 104 (100nF) | KEY2 旁路电容 |
| C8   | 22pF | 晶振负载电容 |
| C9   | 22pF | 晶振负载电容 |
| C10  | 10uF | 复位电路滤波电容 |

## 时钟系统

### 主时钟

- **晶振频率**: 11.0592 MHz
- **晶振型号**: Y1（无源晶振，两引脚）
- **连接引脚**:
  - XTAL1 (STC89C52RC Pin 19): 晶振输入端
  - XTAL2 (STC89C52RC Pin 18): 晶振输出端
- **负载电容**: C8 = 22pF，C9 = 22pF（均对地）

### 时钟特性

- 11.0592MHz 是标准串口晶振频率
- 可精确产生标准波特率（9600 / 19200 / 38400 / 115200），误差率为 0
- 机器周期 = 12 / 11.0592MHz ≈ 1.085 µs

## USB转串口 (CH340G)

### 芯片信息

- **型号**: CH340G（原理图标注为 U1: CH340G）
- **功能**: USB 全速转 TTL 串口，用于程序下载和串口调试
- **封装**: SOP-16

### 引脚连接

| CH340G 引脚 | 信号 | 连接目标 | 说明 |
|------------|------|---------|------|
| Pin 1  | GND   | GND     | 地 |
| Pin 2  | TXD   | MCU P3.0 (RXD) | 串口发送→单片机接收 |
| Pin 3  | RXD   | MCU P3.1 (TXD) | 串口接收←单片机发送 |
| Pin 4  | V3    | —       | 3.3V 内部输出（外接100nF电容到地） |
| Pin 5  | UD+   | USB D+  | USB 差分数据正 |
| Pin 6  | UD-   | USB D-  | USB 差分数据负 |
| Pin 7  | XI    | 晶振/悬空 | 内部时钟，无需外部晶振时悬空 |
| Pin 8  | XO    | 晶振/悬空 | 同上 |
| Pin 9  | CTS#  | —       | 清除发送（流控，一般悬空） |
| Pin 10 | DSR#  | —       | 数据设置就绪（流控，一般悬空） |
| Pin 11 | RI#   | —       | 振铃指示（一般悬空） |
| Pin 12 | DCD#  | —       | 载波检测（一般悬空） |

| Pin 14 | RTS#  | —       | 请求发送（流控，一般悬空） |
| Pin 15 | R232  | —       | RS232 使能（低电平有效） |
| Pin 16 | VCC   | 5V      | 电源输入 |

## 外设接口

### 1. 按键

**数量**: 2个独立按键（KEY1、KEY2）

| 按键 | 元件编号 | 连接MCU引脚 | 上拉电阻 | 滤波电容 |
|------|---------|-----------|---------|---------|
| KEY1 | SW1     | —（原理图未明确标注，需自行连接至P3口） | R1 (10K) 上拉至 5V | C3 (104) |
| KEY2 | SW2     | —（同上） | R5 (10K) 上拉至 5V | C6 (104) |

**按键特性**:
- 默认高电平（上拉状态）
- 按下时为低电平
- 使用时需软件消抖（推荐 10ms 延时消抖）

### 2. 用户LED

**数量**: 2个可编程用户 LED（LED1、LED2）

| LED | 元件编号 | 限流电阻 | 供电 | 说明 |
|-----|---------|---------|------|------|
| LED1 | D4     | R62K（620Ω） | 5V | 用户 LED，低电平点亮 |
| LED2 | D5/D6  | R72K（720Ω）/ R82K（820Ω）| 5V | 用户 LED，低电平点亮 |

> **注**: 原理图中 R62K、R72K、R82K 为阻值标注，实际阻值分别约为 620Ω、720Ω、820Ω，限流保护 LED。

### 3. 复位电路

**方式**: 上电自动复位 + 手动按键复位

| 元件 | 值 | 功能 |
|------|-----|------|
| SW3  | 复位按键 | 手动复位按钮，按下使 RST 引脚拉高 |
| C10  | 10uF | 上电自动复位滤波电容 |
| R16  | 10K | 上拉电阻，维持复位引脚正常高电平 |

**复位原理**:
- 上电瞬间 C10 充电，RST 引脚维持短暂高电平 → 完成上电复位
- 按下 SW3 → RST 引脚被短暂拉高 → 手动复位
- STC89C52RC 复位有效电平：**RST 高电平有效（≥2个机器周期）**

### 4. 串口扩展接口

| 接口 | 引脚 | 说明 |
|------|------|------|
| JP1  | Pin1: 5V, Pin2: TXD, Pin3: RXD, Pin4: GND | TTL串口引出接口 |
| JP2  | Pin1: 5V, Pin2: GND, Pin3: GND, Pin4: GND | 电源引出接口 |

## 开发注意事项

### 1. 电源相关

- 推荐使用 USB Type-C 供电，电压 5V
- 保险丝（SMD1812P110TF）限流保护，发热正常，短路后会自恢复
- VCC 去耦电容（C1 = 104）应尽量靠近芯片引脚放置
- 不要超过 5.5V 给开发板供电

### 2. P0 口使用

- P0 口为开漏输出，**必须外接上拉电阻**（推荐 4.7K～10K）才能输出高电平
- 驱动能力：8个 LS TTL 负载
- 驱动 LED 阵列、数码管时需配合锁存器（如 74HC573）和上拉排阻

### 3. 串口下载

- CH340G 的 TXD → MCU P3.0（RXD）
- CH340G 的 RXD ← MCU P3.1（TXD）
- DTR# 引脚经 RC 延时连接 RST，用于 **ISP 自动下载复位**（部分开发板支持）
- 使用 **STC-ISP** 软件下载，波特率推荐 115200

### 4. 晶振相关

- 11.0592MHz 晶振可精确产生标准串口波特率，误差率为 0%
- 负载电容 C8/C9 = 22pF，选用精度较高的 NPO/C0G 电容
- 晶振走线尽量短，避免靠近 USB 差分线

### 5. 版本区分（90C vs HD）

| 特性 | 90C版本 | HD版本 |
|------|---------|--------|
| EA 引脚 | 无 | 有（接 VCC = 使用内部 ROM）|
| PSEN 引脚 | 无 | 有 |
| P4.4 / P4.5 / P4.6 | 有 | 无 |
| 程序下载 | STC-ISP | STC-ISP |

### 6. 复位注意事项

- 上电复位时间由 C10（10uF）和 R16（10K）决定，时间常数 τ = RC = 100ms
- 复位有效时间需 ≥ 2 个机器周期（约 2.2µs @ 11.0592MHz）
- 复位期间所有 I/O 引脚保持高阻输入状态

### 7. LED 使用

- D4/D5/D6 为低电平点亮（共阳极连接至 5V）
- 在 MCU 引脚输出低电平时 LED 点亮，输出高电平时熄灭
- 驱动电流约 5～10mA，注意 MCU 引脚灌电流能力（单引脚最大 20mA）
